# Warehouse Systems Incident Tracker

A browser-based incident management application designed to demonstrate warehouse systems support, operational issue tracking, and basic incident reporting.

**Live Demo:** [Warehouse Systems Incident Tracker](https://reinergreyson.github.io/warehouse-systems-incident-tracker/)

## Project Overview

The Warehouse Systems Incident Tracker helps users record warehouse technology issues, monitor incident status, filter and search records, and review key operational metrics.

The project simulates a simple workflow for tracking technology disruptions that can affect warehouse operations, inventory accuracy, and system availability.

## Features

- **Incident Management:** Create, view, update, and delete incident records.
- **Status Tracking:** Track incidents through Open, In Progress, and Resolved statuses.
- **Severity Filtering:** Filter incidents by severity.
- **Status Filtering:** Display incidents based on their current status.
- **Incident Search:** Search records to find specific systems and issues.
- **KPI Dashboard:** Display summary metrics for total, open, high/critical, and resolved incidents.
- **Browser Data Persistence:** Retain incident records and updates after a page refresh.
- **CSV Export:** Export incident data for spreadsheet review and reporting.
- **Responsive Interface:** Access the tracker through a modern web browser.

## Data and Limitations

This is a portfolio demonstration project. Incident records are stored in the browser rather than a shared server-side database. Data availability may depend on the browser and device being used.

The application is not a production incident-management system and does not provide centralized multi-user access, authentication, or server-side data storage.
